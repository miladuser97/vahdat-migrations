# config/navigation/

## Purpose
Future site menu/navigation structure — e.g. the list of main menu links
and their labels/paths — kept in one place so every menu, header, and
footer on the site stays consistent and easy to update.

## Allowed contents
- Plain configuration objects/arrays describing navigation links.

## What should NOT be placed here
- The actual menu UI component (use `src/components/layout/`).
- Nothing has been implemented yet — structure only.
