# config/site/

## Purpose
Future general site information — e.g. site name, default SEO
description, contact details, social links — used in multiple places
across the app (page titles, footer, metadata).

## Allowed contents
- Plain configuration objects/values describing the site itself.

## What should NOT be placed here
- Feature-specific settings (those belong with the feature in
  `src/features/<feature>/` once it exists).
- Nothing has been implemented yet — structure only.
